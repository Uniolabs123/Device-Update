ACS712 Controller Updater

Connect your ESP32 device to install the 16-CH ACS712 Modbus Monitor firmware instantly from your browser.

Installation Steps

  1. Plug your ESP32 into your computer via USB.
  2. Click the Connect button below.
  3. Select your device's COM port from the browser popup.
  4. Follow the on-screen prompts to install the firmware.
Unsupported Browser!
ESP Web Tools requires a Web Serial compatible browser like Google Chrome or Microsoft Edge on a desktop computer. Error: You must host this website on HTTPS (like GitHub Pages) or localhost for Web Serial to work!
