UNIO Irrigation Updater

Install UNIO-8RG-B2C3D1 firmware 2.2.3 (Ethernet demo — phase/dry-run lock disabled so relays can be tested).

Installation Steps

  1. Plug the ESP32 into this computer with a USB Type-C data cable.
  2. Use Google Chrome or Microsoft Edge (not the phone browser).
  3. Click Connect & Install below.
  4. Select the ESP32 COM port, then click Install.
  5. Wait until it says success, then unplug USB and leave Ethernet connected.
